## 메일 본문

안녕하십니까, 교육혁신본부 AI융합교육센터 정유선입니다.

「CNU 규정 나침반」에 관심을 가져 주셔서 감사합니다. 규정 나침반은 전남대학교
규정과 지침(총 804건, 17,281개 조문)을 근거로, 질문에 대해 해당 조문의 원문과
출처를 함께 제시하는 AI 검색 서비스입니다. 2026년 AI 활용 성과발표회 출품작으로
개발되었고, 현재 교내에서 사용하실 수 있도록 운영하고 있습니다.

이용 방법을 아래와 같이 안내드립니다.

### 1. 전남대 생성형 AI(AIONI)에서 사용하기 (권장)

별도 설치 없이 AIONI에 도구를 등록하면 바로 사용할 수 있습니다.

1) AIONI에 로그인한 뒤 [에이전트] > [커넥터] > [편집] 메뉴로 이동합니다.
2) 아래 내용을 그대로 붙여넣고 저장합니다.

```json
{
  "mcpServers": {
    "cnu-rule-compass": {
      "description": "전남대 규정 나침반. 교내 규정·지침 804건 17,281개 조문 근거 검색",
      "url": "https://cnu-rule-compass-433006350023.asia-northeast3.run.app/mcp"
    }
  }
}
```

3) 등록이 완료되면 도구 목록에 search_rule 등 7개 도구가 표시됩니다.
4) 대화창에 규정 관련 질문을 입력하면 AI가 자동으로 도구를 사용해 답변합니다.

인증 정보나 API 키는 필요하지 않습니다.

### 2. Claude, ChatGPT 등 개인 AI 도구에서 사용하기

MCP 커넥터를 지원하는 AI 서비스라면 아래 주소 하나로 연결됩니다.

- 커넥터 주소: https://cnu-rule-compass-433006350023.asia-northeast3.run.app/mcp
- claude.ai(웹·앱): 설정 > 커넥터 > 커스텀 커넥터 추가에 위 주소 입력
- Claude Code, Cursor 등 개발 도구: 위 1번의 JSON을 MCP 설정에 추가
  (도구에 따라 `"type": "streamable-http"` 필드를 요구하는 경우가 있습니다)

### 3. GitHub 소스 코드

서비스 코드는 GitHub에 공개되어 있습니다.

- https://github.com/yousunjung84-edu/cnu-rule-compass

한 가지 유의하실 점은, 저장소를 내려받아 직접 실행하는 경우 데모용 샘플
(123개 조문)으로 동작한다는 것입니다. 규정 전체 데이터는 위 1, 2번의
운영 서버를 통해서만 제공됩니다. 코드 구조나 동작 방식을 참고하시는 용도로
활용해 주시기 바랍니다.

### 질문 예시

구체적으로 질문할수록 정확한 조문을 찾습니다.

- "재입학 절차와 대상을 알려줘" (학칙, 교학규정, 재입학 세부지침까지 함께 답변)
- "전임교원 겸직 허가 기준이 뭐야?"
- "도서관 대출 규정을 알려줘"
- "연구비 사용 기준 중 인건비 계상 기준은?"
- "연구비 중앙관리지침의 2018년 당시 내용을 알려줘" (일부 규정은 과거 시점 판본 조회 가능)

### 이용 시 유의사항

- 답변은 참고용입니다. 학사 행정과 규정 적용의 최종 근거는 규정 원문이며,
  답변에 포함된 원문 링크에서 반드시 확인해 주시기 바랍니다.
- 규정 개정 사항은 매월 1회 자동으로 반영됩니다. 답변에 표시되는 수집 일자를
  참고해 주십시오.
- 생성형 AI 사용 기준 등 아직 교내 규정이 제정되지 않은 사안은 "근거 조문이
  확인되지 않는다"고 답변합니다. 이는 서비스 오류가 아니라 해당 규정이 없다는
  의미입니다.
- 강의료 단가표 등 표 형태의 일부 문서는 검색 대상에 포함되어 있지 않습니다.

사용 중 불편한 점이나 잘못된 답변을 발견하시면 회신 주시기 바랍니다.
