# 코퍼스 지도

검색이 반복 실패하거나 커버리지를 판단해야 할 때 읽는다.
**기준 서버: cnu-rule-compass v1.5.0 · 스킬 v1.4.0.**

> 수록 규정 목록과 규모는 이 문서에 적어두지 않는다. 문서는 낡지만 도구는 낡지 않는다.
> - 규정 목록 → `list_rules(division?)`
> - 규모·편제 분포·수집일시 범위 → `get_corpus_stats()`
>
> 여기 남긴 것은 **도구가 알려주지 않는 판단 지식**뿐이다.

## 1. 두 계층

코퍼스는 출처가 다른 두 계층으로 구성된다. 이 구분이 신뢰도 판단에 직결된다.

| 계층 | 출처 도메인 | `source_key` 형태 |
|---|---|---|
| 규정 (상위) | `law.go.kr` (국가법령정보센터 학칙공포) | 13자리 숫자 (예: `2200000157745`) |
| 지침 (하위) | `jnu.ac.kr` (교내 행정규정 게시) | 4자리 숫자 (예: `4908`) |

`편제`가 `규정집/`으로 시작하면 규정 계층, 그 밖(`학사과`·`정보화본부` 등)은 지침 계층이다.
`list_rules`의 `계층` 필드가 이를 그대로 알려준다.

**규정이 지침보다 상위다.** 두 계층이 충돌하면 규정을 우선하고, 충돌 사실 자체를 사용자에게 알린다.
지침 조문이 규정을 인용하는 경우가 많다 — 예: `수업관리 지침` 제27조는 본문에서
"「전남대학교 교학규정」 제32조에 의하여"라고 명시한다.
이 연결고리는 `get_related_articles`가 자동으로 해소해 준다.

## 2. 학사 문의의 규정 서열

```
전남대학교 학칙 (규정집/학칙 및 학위수여)   ← 최상위
   └─ 전남대학교 교학규정 (규정집/교무행정)  ← 학칙의 시행 세부
        └─ 수업관리 지침 (학사과)             ← 실무 절차
```

**대학원생 문의는 소속을 먼저 확인한다.** 일반대학원·정책대학원·교육대학원·
법학전문대학원·농생명산업대학원·글로컬미래전략대학원의 교학규정이 각각 별도로 존재하며
조문 내용이 다르다. 학부 기준 조문을 대학원생에게 그대로 적용하지 않는다.

`전남대학교 사범대학부설고등학교학칙`은 **부설고등학교** 규정이다.
대학 학사 문의의 근거가 될 수 없다. "퇴학", "자퇴" 등에서 오탐으로 올라온다.

### 입학·재입학 시기

`전남대학교 학칙 제25조(입학시기)` — 편입학·재입학을 포함한 입학 시기를
**학기개시일로부터 25일 이내**로 정한다. 재입학 문의에서 "언제까지 가능한가"의 근거다.

> ⚠️ 이 조문 본문에는 원문 손상이 있다(`입학(편?재입학 포함)` — 가운뎃점이 `?`로 저장됨).
> 손상은 **정본 제공처(law.go.kr) 응답 자체**에 있어 재수집으로 고쳐지지 않는다.
> 인용할 때 원문대로 옮기되, 필요하면 "원문 표기상 문자 손상이 있다"고 밝힌다.
> 임의로 `편·재입학`으로 고쳐 쓰지 않는다 — 추정 복원은 날조다.

## 2-3. 교원 인사·복무 계열 (교원 문의의 주 경로)

교원 문의는 이 스킬의 주요 용도다. 계열이 **규정과 지침 양쪽에 흩어져 있으므로**
편제로 좁히지 말고 아래 서열을 따라간다. (전체 목록은 `list_rules(division=...)`)

| 사안 | 규정 (상위) | 지침 (실무) |
|---|---|---|
| 임용·승진·파견·복무 | 전남대학교 교원 인사에 관한 규정 (70조문) | — |
| 비전임·강사 | 비전임교원 인사에 관한 규정 (57) / 강사 인사에 관한 규정 (30) | 강사료·강의료 지급 지침 (연도별) |
| **겸직·영리업무** | — | **전임교원 겸직에 관한 지침 (16조문, 교무과, source_key 4609)** |
| 업적평가 | 교수업적평가규정 (20) | 성과급적 연봉제 운영 지침 |

### 겸직 지침 읽는 법 (2026-08-10 검증)

- **제1조**가 상위 법령 4종을 인용한다 — `국가공무원법` 제64조, `교육공무원법` 제19조의2,
  `교육공무원임용령` 제7조의5, `국가공무원 복무규정` 제26조.
  전부 `external_law`(코퍼스 밖)이므로 조문 내용을 지어내지 말고 법령 확인을 안내한다.
- **제5조·제6조에 삭제된 호가 있다**(①1호, ②5호, 2024. 3. 22. 개정).
  호 번호가 밀리지 않으므로 `repealed_items`를 확인하지 않고 "제1항 제1호"를 인용하면
  삭제된 호를 지목하게 된다.
- **제7조**는 1개월 초과 외부강의를 따로 규율한다 — 외부강의 문의는 기간으로 조문이 갈린다.
- **제9조가 허가절차·제출서류를 별표에 위임**한다. 별표는 코퍼스에 없다
  (`attachment_not_collected`, `reason_code: parser_scope` — 원문 HWP에는 텍스트가 있으나
  조문 단위 수집 범위 밖). "규정에 없음"이 아니라 "미수집"으로 안내한다.
- 본문이 **반각 낫표 `｢ ｣`**를 쓴다. 인용 시 원문 표기를 그대로 옮긴다.

## 3. 확인된 공백 — AI 활용 규율

**AI 활용(생성형 AI 사용 범위·표절·수업 활용)을 직접 규율하는 조문이 확인되지 않는다.**

⚠️ 다만 **`인공지능` 어휘 자체는 코퍼스에 있다.** 규정 계층 확장으로 들어온
`전남대학교 인공지능융합연구소 규정`(설치·조직·사업), `사무분장 규정` 등이다.
**설치 규정은 활용 규율이 아니다.** 검색이 결과를 준다고 근거가 생긴 것이 아니다.

v1.1.0에서는 이 판정을 눈대중이 아니라 서버 `hints`로 한다.

```
search_rule("생성형 인공지능 챗봇")
→ count: 0, hints.query_terms_unmatched: ["생성형", "챗봇"]
```

`query_terms_unmatched`에 해당 어휘가 들어 있다 = **코퍼스 어휘집에 그 개념이 없다.**
"검색을 잘못했나"와 "규정이 없나"를 구별해 주는 유일한 신호다.

**다만 이 절은 관측 기록이지 전제가 아니다.** 코퍼스 갱신으로 AI 조문이 신설되면
이 절을 믿고 "없다"고 답하는 것 자체가 오답이 된다. 매번 다시 확인한다.
제정된다면 편제상 `정보화본부`(외부 서비스 정보 반출) 또는 `학사과`(수업 운영)가 유력하다.

AI 문의가 들어왔을 때 근거로 **쓰면 안 되는** 대표 오탐:

| 조문 | 실제 규율 대상 | 왜 안 되는가 |
|---|---|---|
| 연구윤리진실성위원회 규정 제4조 | 연구자의 연구부정행위 정의 | 학부 과제 수행 규범이 아니다 |
| 연구비 중앙관리지침 제19조 | 연구비 지급중단·회수 | 학생 문의와 무관 |

## 4. 검색이 실패할 때의 재시도 전략

**순서가 중요하다.** 위쪽이 훨씬 효과적이다.

1. **`hints`를 먼저 본다.** `query_terms_unmatched`가 비어 있으면 어휘는 있다 —
   (단 AI 문의는 어휘가 있어도 규율 대상이 다를 수 있다. §3 참조) —
   검색 방식의 문제이므로 2~4로 간다. 채워져 있으면 개념 부재 쪽을 의심한다.
2. **상호참조를 따라간다.** `get_related_articles(record_id, direction="both")`.
   `inbound`가 여럿이면 그 조문이 사안의 중심이다.
3. **상위 규정을 조문번호로 직접 조회한다.** 학칙·교학규정은 목차를 훑듯 조회해도 된다.
   `제○조의2` 형태도 확인한다.
4. **구어체 → 규정 용어로 변환한다.** 코퍼스는 동의어를 확장하지 않으므로 이게 결정적이다.

   | 구어 | 규정 용어 |
   |---|---|
   | 다시 들어가기 | **재입학**(제적·퇴학자) / **복학**(휴학자) — 둘은 다르다 |
   | 학교 그만두기 | 자퇴, 퇴학, 제적 |
   | 성적 이의신청 | **성적 정정**, 성적 처리 — 코퍼스에 `이의신청`은 이 맥락으로 없다 |
   | 수업 빠지기 | 결석, 출석 |
   | 학교에서 잘림 | 제적, 징계 |
   | 챗지피티 | 대응 규정 용어 없음 (§3) |
   | 부업 / 알바 / 밖에서 일 | **겸직**, 영리업무 |
   | 외부 강의 / 출강 | **외부강의** (1개월 초과 여부로 조문이 갈림 — 겸직 지침 제7조) |
   | 회사 임원 / 이사 | 사외이사, 임직원 |
   | 유튜브 / 방송 | 인터넷 개인방송 |
   | 정학 / 처벌 / 벌 | **징계** (근신·유기정학·무기정학·제적) |
   | 커닝 / 부정행위 | 시험 부정행위 |

   | 연구소 없애기 | 통·폐합, 폐소 |
   | 의결정족수 | **개념어 단독 + 조문 문언 병행 검색** — '재적위원 과반수 출석 찬성 의결' |

5. **`k`를 늘린다** (8 → 10).
6. **계층을 오르내린다.** 지침 ↔ 교학규정 ↔ 학칙.
